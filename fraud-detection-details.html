Fraud Detection Platform

An end-to-end credit-card fraud detection platform built around a Random Forest classifier and REST API. It brings together imbalanced transaction data, model evaluation, PostgreSQL persistence, experiment tracking, a dashboard, automated testing and AWS integration.

Project objective

Detect potentially fraudulent credit-card transactions and make predictions available through an API, while retaining transaction and prediction data and exposing useful information through a dashboard.

Dataset and class imbalance

The dataset contains 284,807 transactions, including 492 frauds (approximately 0.173%). Because fraud is rare, accuracy alone can be misleading; precision, recall, F1 score and ROC-AUC help describe model performance more usefully.

Machine learning model

Random Forest

Random Forest combines the predictions of multiple decision trees to classify transactions as legitimate or potentially fraudulent. In the recorded project metrics, the model achieved:

  • ROC-AUC: 0.9796 — measures how well the model separates the two classes across thresholds.
  • F1 score: 0.8404 — balances precision and recall.
  • Precision: 0.8778 — proportion of flagged transactions that were actually fraudulent.
  • Recall: 0.8061 — proportion of fraudulent transactions detected.

Architecture and API

Transaction data → Random Forest inference → Flask REST API → PostgreSQL persistence and dashboard visualization. Docker Compose is used to bring the services together, while the cloud setup includes S3, Lambda and API Gateway.

Recorded API endpoints

  • /api/predict — submit a transaction for prediction.
  • /api/predictions — access prediction history.
  • /api/model — retrieve model information.
  • /api/metrics — retrieve model metrics.
